# English Premier League (EPL) Power BI Dashboard

## Overview
This project is a class-based analytics exercise using **Power BI** to design and develop an interactive dashboard focused on the **English Premier League (EPL)**. 
The goal is to demonstrate data modeling, visualization, and storytelling skills by transforming raw football data into meaningful insights.

## Objectives
- Practice end-to-end dashboard development in Power BI  
- Apply data cleaning, modeling, and transformation techniques  
- Create clear, interactive visualizations that support analysis and decision-making  
- Communicate insights effectively through dashboard design  

## Dashboard Features
- Overview of EPL teams and seasonal performance  
- Match statistics and key performance indicators (KPIs)  
- Comparative analysis across teams and time periods  
- Interactive filters and slicers for exploratory analysis  

## Tools & Technologies
- **Power BI** – Data modeling, DAX measures, and visualization  
- **Microsoft Excel / CSV** – Source data preparation  

## Data Source
Publicly available English Premier League datasets used for educational purposes only.

## Key Learnings
- Designing user-friendly dashboards with a clear analytical narrative  
- Building data models and calculated measures in Power BI  
- Translating business or domain questions into visual insights  

## Disclaimer
This work was completed as part of a project and is intended solely for portfolio demonstration purposes. It is not affiliated with or endorsed by the English Premier League.


## How to Use
1. Download the `.pbix` file from this repository  
2. Open it using **Power BI Desktop**  
3. Explore the dashboard using the interactive filters and visuals
